# docs

## Naming convention

```
<YYYY-MM-DD>---<kind>---<slug>.md
```

The **date** is when the doc was first written. It does not change when the doc is edited.

| Kind | What it is |
|---|---|
| `plan` | How we intend to build something. Decisions of record accumulate here as they're made. |
| `rfc` | A proposal put to someone else for a decision. |
| `roast` | One idea, one run — lives in `roasts/`, not here. |
